# №9069 Alluvium — process

Alluvial fans from above: river mouths spill arcs of sediment that overlap
and settle over each other. Seeds are checked so the fans interleave instead
of sitting apart.

Built by Bug (2026-10-11) as a replacement for the deleted №9069 Bastion.
Full-bleed on phones (physical-screen detection), square on desktop.
Canvas CSS size pinned to the viewport (fixes 2x rendering on high-DPR phones).
