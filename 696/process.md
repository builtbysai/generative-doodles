# No.696 "Shibboleth Field" — process

## Concept

Doris Salcedo's *Shibboleth* (EXPANSION #85 doris-salcedo, prompt block 1): a crack cut through the floor of the Turbine Hall, a wound in the building that separates rather than decorates. Here the ground plane itself is the whole piece: an almost-black field with a subtle seeded grain, otherwise empty. Across it, one fracture system slowly propagates — a main fault wandering edge to edge with a handful of tapering side branches — while a faint ember underglow breathes along the freshest edges, like heat seen through a fissure. When the fault completes, the field heals back to plain ground and a different fault begins. There is no scenery, no text, nothing else to look at. The crack is the subject.

## Construction

- Single self-contained `index.html`, canvas 2D only, no external assets. Strict four-colour palette: ground #121110, crack interior #050505, crack edge #E8E0D4, underglow #FF6B2C (low alpha only). The only text is the `<title>`.
- Canvas size comes from the Visual Viewport API, with resize listeners on both `visualViewport` and `window`; `draw()` pins `canvas.style.width/height` in px every frame. Phone detection uses `window.screen` (min dimension < 700px), with the aspect rule (h > w*1.15) as fallback only. The ground is full-bleed at every size, so the page ground and the piece ground are the same #121110.
- Ground grain: 2,800 tiny speckles in normalised coordinates from one fixed mulberry32 stream (independent of the fault cycle), drawn each frame in the crack-interior and crack-edge tones at very low alpha. The grain is identical in every cycle; only the fault changes.
- Fracture generation: each cycle's fault is precomputed from a seed derived from the cycle index (mulberry32) and cached. The main fault is a random walk from a seeded edge origin toward a seeded target point on the far side: heading inertia plus a gentle clamped bias toward the target, so the path wanders organically but always crosses the field. Width tapers along its length from 6px at the origin to about 2px at the far tip (widths are authored at a 720px reference and scaled by min(viewport)/720). Then 3–6 side branches are attached at spaced points along the main fault, leaving it at 30–60 degrees to the parent heading, each starting at roughly two-thirds of the parent's local width and tapering to 1px. Every candidate step of every branch is tested against all already-committed segments, and the branch stops before any crossing, so the system never crosses itself.
- Growth and reveal: every segment carries an appearance time on a shared growth timeline. The main fault occupies the first 58% of the timeline; each branch starts when the growth front passes its attachment point and finishes by 98%. A 50-second cycle drives it: 0–40s propagation (a gently eased reveal), 40–50s healing (the whole system fades out with a smoothstep), then the next cycle index seeds a new fault on a new path. State is a pure function of an anchored epoch plus the cycle index.
- Rendering, in layers: (1) underglow — segments whose appearance falls within the freshest 30% of the growth front get two flat, wide, low-alpha ember strokes underneath, intensity falling with age and pulsing slowly; no gradients, no blur. (2) crack body — instead of stroking segments, the renderer stamps heavily overlapped discs along each revealed segment: first a pale rim pass (#E8E0D4 at alpha 0.30, radius = half the local width), then the dark interior (#050505, radius = 0.66 of that). The overlap makes the fissure read as one continuous tapered crack with no visible joints.
- Tap: a quick tap advances the anchored epoch to the next cycle index and restarts the clock, so a fresh fault begins immediately on a new seeded path. There is no drag and no other interaction; this one is for watching.
- Determinism: frame one is the synchronous draw at cycle t = 0 — plain grained ground with only the first fraction of the origin segment (which begins just off-frame) entering. The animation clock is anchored elapsed time; the loop runs only when `requestAnimationFrame` exists (typeof-guarded). No `Date.now`, no `Math.random`, no offscreen canvas, no `ctx.filter`, no shadowBlur, no audio, no microphone. An inert `?seed=tNN` query hook can force the cycle clock for QA renders; it does nothing in normal viewing.

## QA log

- Rendered with `node ~/workspace/tools/render-piece.js` (node-canvas harness; no rAF, no AudioContext, no `document.createElement` in that environment, and the piece runs clean there):
  - `qa-desktop.png` (1280x900): near-black ground with fine grain across the whole frame, fault not yet visibly entered at t = 0; nothing clipped.
  - `qa-mobile.png` (390x844): same grained ground full-bleed on the tall frame; phone rule engaged via `window.screen`.
  - `thumb.png` (720x720): plain dark grained field, as intended for the first frame of a 50-second propagation.
- Determinism gate: `thumb.png` rendered twice and compared with `cmp`: byte-identical. The second render was deleted.
- Forced-state checks (throwaway renders in /tmp via the `?seed=` hook, read back, then deleted): t = 25s showed the main fault wandering across the field with three branches grown and ember warmth along the fresh branch tips and the active end of the main fault; t = 38s showed the fuller system, one branch reaching the top edge, glow nearly cooled. Neither render showed segment joints or self-crossings.
- Fix round during QA: the first t = 25 render drew the crack as per-segment strokes and read as a segmented pale outline (a stitched tube, not a fissure). The crack body was rebuilt as overlapped disc stamping with a quieter rim (see Construction), the walk's heading jitter was loosened so the fault wanders more, and all renders were redone and the byte-compare re-run.

## Deviations

- None from the prompt's substance. Two implementation notes: the prompt's "perlin field" stress bias is realised as heading inertia plus a clamped target bias inside the seeded walk (a closed-form deterministic substitute that produces the same organic curving); and the underglow's "fading to transparent" is done with layered flat strokes at falling alpha, per the house no-gradient rule used across this series.
