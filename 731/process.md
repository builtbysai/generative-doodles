# No.731 Fake ID

EXPANSION #89 paul-ramirez-jonas, prompt block 4. After Fake ID (2017, New Museum): a new ID built from whatever is on your person.

## Concept

A wallet spills five mismatched cards across a table: a driver's license, a membership card, a banknote, a transit card, a library card, each carrying a different invented name, number, and expiry. A brass ID machine across the top assembles a NEW ID from the spill, taking exactly one field from each card. The finished card is stamped SPECIMEN and is clearly a fiction. All data is invented placeholder text; nothing is real personal data, and the flat diagrammatic drawing keeps it far from any identity-theft framing.

Field mapping (the assembly sequence, in order):

1. Photo slot from the driver's license (an empty outlined frame, crossed, labeled PHOTO).
2. Name from the library card.
3. Number from the transit card.
4. Portrait from the banknote (flat oval with an ink silhouette).
5. Expiry from the membership card.

## Construction

Single self-contained index.html, canvas 2D, no external assets. The scene is composed in a 1000 x 1000 design space fitted to the smaller viewport dimension and centered; the table tone fills the whole frame and the page ground, so phones keep the composition's shape on the piece's own background color.

- Determinism: each epoch (wallet spill) is generated by a mulberry32 seeded RNG: five distinct names drawn from an invented pool, seeded digit strings for every number and serial, seeded expiries, seeded fan jitter. Animation is closed-form: card poses during a spill are eased interpolations from the wallet position as a function of elapsed time; assembly phases (slide-out, five transfers, stamp) are pure functions of the time since the machine tap. Frame one is a synchronous draw at t = 0 with the initial spill already settled (spill start time offset negative), never derived from any wall clock. The animation loop is anchored to elapsed-since-load and rAF is typeof-guarded, so the headless QA renderer draws the same first frame with no rAF present.
- Interaction (taps only, recorded against the elapsed clock): tap the wallet to spill a fresh seeded set (cards tumble out from the wallet with rotation and a small arc). Tap the machine to assemble: a blank cream card slides out of the brass slot down to the stand, then five transfers run in mapping order, each with a dashed connector line whose dash offset animates, a travelling ghost of the field (photo frame, text line, or portrait) moving along it, and the field fading in on the new card. A red SPECIMEN stamp then slams on with a scale ease. Taps during assembly are ignored, so the assembly cannot be skipped. Tap the finished card to flip it with a scale-x animation; the back carries a barcode whose bar widths are built from the mixed digits (transit number + membership number + membership expiry), the mixed number printed beneath, and a small SPECIMEN line. Tap the machine again to re-run the assembly; tap the wallet any time to respill.
- The machine's status lamp (membership red) pulses while assembling, steady otherwise, as a plain function of time.
- Canvas size comes from the Visual Viewport API with resize listeners on visualViewport and window; canvas.style.width/height are pinned in px inside draw(). Phone detection uses window.screen (min dimension < 700px) with aspect h > w*1.15 fallback only; the fitted-square composition needs no separate phone layout.
- Palette is strict: table #3A3F4A, license #4A7FB5, membership #C0392B, banknote #7BA05B, transit #E8A33D, library #8A6FB5, machine brass #B08D3E, new ID cream #F5F1E6, ink #1A1A1A. Alpha variants of these tones only. The wallet is ink with a brass clasp, staying inside the palette.
- Text is limited to the specced content: card titles and fields, the PHOTO slot label, the SPECIMEN stamp, and the barcode number on the back. No hint text, no other labels.

## Deviations

- Frame one shows the first spill already settled rather than an unspilled wallet: the brief's own read-back spec asks frame one to show the five cards fanned with the stand empty, and a settled spill makes the thumbnail carry the piece. Recorded here per the brief's instruction to choose and record.
- The banknote portrait sits on the left of the note instead of the right (see QA fix): the fan overlap hid it on the right, and the portrait must be visible because the machine visibly pulls it during assembly.
- The ID's brass header stripe is a plain band with no header text: the brief limits text to the specced card fields, the SPECIMEN stamp, and the barcode, so the new ID carries no title line.
