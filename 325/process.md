# No.325 Buffalo Plaid Bee

After Debbie Sharman's buffalo plaid bee entry, this piece covers the whole frame with a bold plaid on a cream ground. The plaid is built from two sets of bands drawn in order on the single canvas. The vertical bands run the full height first and the horizontal bands run the full width second, with the composite operation set to multiply while they are drawn, so each crossing darkens where a red band and a black band overlap and darkens again where two red bands cross. Thin cream lines separate the bands, so the cream ground stays visible as a fine grid through the checks. The operation is reset before anything else is drawn. Bands repeat in runs of two checks, red then black, so the checks read large and punchy, like a woven textile cut to fill the frame edge to edge.

Resting on the plaid are exactly twelve cartoon bees, counted and asserted in the code. The frame is a lattice of four blocks across and three down, and each block holds a three by three group of checks with one bee resting in it at its own authored offset from the block centre. Each bee is a honey oval with two black stripe bands, a black head with a cream eye and antennae, a small stinger, and two smoke wings. No bee is placed by chance; every resting offset, wing phase, scale, facing and flight radius is in an authored table.

The idle motion is a twenty second seamless loop. The plaid never moves. The only motion is in the wings: each bee runs a tiny wing-shiver cycle on its own staggered phase, sixty shivers per loop, so the shiver pattern lines up again exactly at twenty seconds and the frame there matches the frame at zero. The first frame opens with the shivers already mid cycle, each bee at a different point in its flutter.

Dragging across the plaid disturbs the bees. Any bee whose centre sits within one hundred and forty design units of the pointer lifts off and flies one small circle, tangent at the spot where it sat, finishing the loop in one point two seconds. While the pointer stays down a lifted bee waits at its spot, and when the pointer lifts, each flying bee glides down onto the centre of the nearest check, keeping its own authored resting offset inside that check. A drag that passes near no bee changes nothing. Nothing reloads and nothing is reseeded, and all marks are drawn directly on one canvas each frame from the band and bee tables.
