# Generative Doodles

Generative art, one piece at a time. Each piece is a small program, drawn live in your browser.

**Gallery:** https://builtbysai.com/generative-doodles/

Each piece lives in its own folder as a single self-contained HTML file. Most are seeded: click a piece for a new variation, or append `?seed=12345` for a specific one.
