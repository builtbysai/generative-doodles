# Generative Doodles

A daily practice of generative art — code doodles, interactive pieces, and plotter sketches.

**Philosophy:** Study first, then create. Every piece is an original exploration of a technique, not a copy. Quality over quantity — no filler.

## Structure

- `study/` — Technique notes from studying master generative artists. One file per artist/site.
- `doodles/` — Daily creations, each a self-contained single HTML file. Dated, with a note on technique and inspiration.
- `plotter/` — Pen-plotter-friendly SVG pieces.

## Study list

Masters: Tyler Hobbs, Matt DesLauriers, Gorillasun, Anders Hoff (inconvergent), Hakim El Hattab, yuru yura, Kaesve, and the CodePen masters (DonKarlssonSan, scorch).

Galleries: fxhash, OpenProcessing, #genuary.

Tutorials: generativeartistry.com, bit-101, Codrops.

## Running a doodle

Each doodle is a single self-contained HTML file. Open it in any browser. Most are seeded — refresh for a new variation, or append `?seed=12345` for a specific one.
