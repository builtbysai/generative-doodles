# №441 Pomegranate Crown

## Concept
Maité Léon's glossy single-subject still-life (EXPANSION #51, prompt 1): one enormous pomegranate, split open with ruby seeds, floating on a deep textured indigo ground. Maximalist light on one object, everything else is ground. Stylised enamel gloss, never photoreal; no drop shadow, no UI, no hint text. The specular light travels slowly across the rind on a 6s cycle, the seeds pulse faintly, and four dust motes drift on lissajous paths. Dragging rotates the light source around the fruit; double-tap deals the next fruit from a fixed authored table (pomegranate, fig, persimmon, citrus slice), each drawn in the same layered radial-gradient gloss grammar.

## Construction
- Single self-contained index.html, canvas 2D only. Canvas sized from the Visual Viewport API (visualViewport width/height, resize listeners on visualViewport and window); canvas.style.width/height pinned in px inside draw() every frame. Phone detection via window.screen physical size (min dimension < 700px), aspect h > w*1.15 as fallback only. The composition is a centered subject that scales with min(W,H) and keeps its shape at phone sizes; the page ground is the piece's own indigo.
- Ground: #2E2E96 fill, a soft radial lift at centre, and a paper-grain field of 1100 specks held as JS data (seeded PRNG, mulberry32) and drawn directly each frame. No offscreen canvases, no sprites, no document.createElement anywhere.
- Pomegranate: body is a radial-gradient ellipse (lit core #B23347 through rind #8A1F2D to a #57101D edge), a six-spike calyx crown at the top, and the split drawn as a rotated pith ellipse (#F3D9C8 to #E8B4B8) with five membrane curves and 52 seeded seeds in #B3123F, each with a darker under-ellipse, a #FF6B8A glint toward the light and a white catch dot. The split edge carries a pale #E8B4B8 lip on the light side and a dark rind lip below. Seeds pulse at ±5.5% scale on individual phases.
- Shared gloss grammar for all four fruits: an anisotropic gloss band and two giant soft white speculars (a broad wash plus a hot core) clipped to the body, positioned from the light vector; a cool rim arc in #7FA8E0 on the edge away from the light. Fig: deep violet pear body (#5B2A6E to #2C1038) with a rose cut face (#D77E96 family) and 110 cream speckles. Persimmon: burnt orange squat ellipse (#D9622B family) with faint lobes and a four-lobed brown calyx. Citrus slice: rind ring #D97416, pith ring #F7E8C8, eight gradient wedges with per-segment glints.
- Light model: light angle = drag-set base angle + a seamless 0.9 rad sway, sin(2πt/6), so the highlights travel across the rind on the prompt's 6s cycle with no loop seam. Drag sets the base angle from the pointer angle around the fruit centre (compensated for the sway, so the light tracks the pointer). Double-tap (two un-moved pointer-ups within 350ms) advances the fruit table; index 0 (pomegranate) at load. State changes deal only from the fixed authored table, never from a clock seed.
- Determinism: the synchronous first frame is drawn at the constant phase PHASE0 = 1.5s; the rAF loop (typeof-guarded) is anchored as PHASE0 + elapsed-since-load. All randomness comes from fixed-seed PRNGs at load. No frame is ever drawn from Date.now().
