# No.833 — Any Song Has to Be Both

EXPANSION #102 john-cale, PP2 "Elegant and Brutal". Shipped title is the
block's Title suggestion.

## Concept

Cale's standing rule — any song has to be both elegant and brutal —
enforced as a strict two-register alternation on the "House" template.
An ELEGANT phase: one thin sepia line draws slow cursive arcs across a
moorland-grey and heather ground while the ghost refrain "I think I'm
gonna die in this house" passes through in large quiet type. A BRUTAL
phase: a hard cut to a red-black duotone field where solid clang blocks
slam in one by one. There is no blend and no fade anywhere: the cut is
the content. The ghost text, caught mid-passage by the cut, is
interrupted mid-word simply by ceasing to exist.

## Construction

Phase machine (closed form). State lives in an anchor list. An anchor
records, at its time: the phase kind, the elapsed time already spent in
that phase, the cycle index, the start time of the current cycle's
elegant phase, and the phase durations in effect from that anchor on.
stateAt(t) walks forward from the last anchor at or before t, consuming
whole phases until it lands inside one, so the phase, elapsed time,
cycle, and cycle start at any t are a closed-form function of the
anchors. The frame clock is anchored to the first rAF timestamp;
Date.now is never read.

Frame one. The initial anchor starts 8 s into an elegant phase
(elapsed 8 of 20 s), so the synchronous first draw shows the cursive
arc about 45% drawn (progress eased by smootherstep over the first 85%
of the phase) and the refrain present and quiet. draw(T_OFF) runs
before the rAF loop starts; the loop re-anchors elapsed time to its
first timestamp so the browser's first frame matches the headless
frame exactly.

Balance drag. Dragging vertically sets a balance b in [-1, 1]
(b = clamp(startBalance + (startY - y) / (0.6 * H))). Durations derive
from it: elegant = clamp(20 + 10b, 10, 30) s, brutal =
clamp(6.5 - 3.5b, 3, 10) s (the 6.5/3.5 centering puts the untouched
default at the specced 20 s / 6 s). On release an anchor is pushed and
the new durations govern from that moment, including the remainder of
the phase in progress. Bounds are as briefed: elegant 10-30 s, brutal
3-10 s.

Seeded shapes. Each elegant cycle's cursive path is generated by
mulberry32(seedBase + cycle * 1013): six cubic segments wandering the
upper two-thirds, sampled to a polyline and stroked twice (a wide,
faint pass under a thin core pass), both in the sepia. Each brutal
cycle's clang blocks come from mulberry32(seedBase + cycle * 7717):
6-10 rectangles in a fixed rotation of brutal black / neon red /
duotone red, each with a slam fraction between 0.05 and 0.67 of the
phase; a block is drawn whole the moment the phase elapsed passes its
fraction — instant appearance, zero easing. The brutal ground is the
duotone red, full frame.

Mid-word cut handling. There is no crossfade state and no transition
code at all: draw() branches on the phase kind and paints one register
or the other. The refrain's drift position is a function of the
elegant phase's progress only (centre x from 0.78W to 0.22W across the
phase), so when the walk crosses the boundary the text is gone between
one frame and the next, wherever it had reached — mid-word by
construction. The audio follows the same rule: the pad gain is driven
to zero with a 0.03 s time constant on entering brutal, against 0.45 s
swells in elegant.

Ghost type. The refrain is set on canvas (no HTML overlay, per the
renderer constraint) in italic Georgia at a size solved so the string
measures 1.32 x frame width (1.12 x on phones), so it is clipped by
both frame edges. Its colour is a 50/50 mix of the sepia and the
moorland grey — both strict-palette tones — drawn at alpha 0.45: the
brief's low-alpha parchment-grey, realised without leaving the
palette.

Double-tap reseed. A double-tap appends {t, base} to a reseed list;
the seed base for a cycle is the latest reseed at or before that
cycle's elegant start, so reseeding governs every cycle that begins
after the tap, arcs and blocks alike.

Audio. Lazy and guarded: the AudioContext is created inside the first
pointerdown only, behind a typeof check, so the piece runs silently
where audio is unavailable. Elegant: two sine oscillators (110 Hz,
164.81 Hz) through a gain that swells in elegant and is cut in brutal.
Brutal: a filtered noise burst (bandpass 650-1170 Hz, 0.16 s decay)
fired once per newly slammed block, counted from the same closed-form
state that draws the blocks. Master gain 0.14 into a compressor.

House rules. Visual Viewport sizing with resize listeners on both
visualViewport and window; canvas pinned in px inside draw(); phone
detection via window.screen (min dimension < 700) with the aspect
fallback; rAF typeof-guarded; no gradients, no shadowBlur, no
ctx.filter, no offscreen canvas; the only visible text is the refrain
and the <title>. An inert QA hook (?seed=brutal, set by the render
tool's seed argument) offsets the clock so frame one lands inside a
brutal phase for verification; it changes nothing without the hook.

## QA log

- Rendered with the house renderer (node-canvas, no AudioContext —
  the piece rendered cleanly in silence at every size):
  qa-desktop.png 1280x900, qa-mobile.png 390x844, thumb.png 720x720.
- Determinism: thumb.png rendered twice and cmp-compared
  byte-identical. The duplicate was deleted.
- Desktop frame one: moorland grey over a heather lower band, the
  sepia cursive arc mid-draw in the upper field, the refrain in large
  quiet italic type centred and clipped at both frame edges. As
  specced.
- Mobile: arc and refrain hold the tall frame; the refrain still
  overflows and clips by design; nothing clipped wrongly.
- Brutal throwaway (rendered via the ?seed=brutal hook at piece
  t = 14 s, then deleted): full-frame duotone red ground, black and
  neon-red clang blocks already slammed with hard, uneased edges, no
  trace of the elegant layer — the cut reads as a slam, not a fade.
- Deviations: none from the brief. Two realisations worth noting:
  the ghost colour is a mix of two palette tones (sepia + moorland
  grey) rather than a seventh colour, and the brutal ground is the
  duotone red so that black clang blocks read against it (black on the
  brutal black alone would vanish).
