# No.317 Monoline Study

After Coral Cockatoo's monochromatic monoline drawings: single-weight black line drawings of Australian botanicals on white paper, with no fill anywhere in the specimens themselves. Three specimens cycle in a fixed order, a gum blossom, then a wattle spray, then a banksia cone, and exactly one specimen is on screen at a time, asserted in the code along with the count of three in the cycle. Each specimen sits centred with generous white margins around it.

Each specimen is a set of real authored botanical paths, drawn in a deliberate order: the stem first, then the architecture, the cup and rim and leaves of the gum blossom, the pom outlines and phyllodes of the wattle, the cone outline and leaves of the banksia, and only then the detail, stamen filaments with dot tips, radiating ticks inside the wattle poms, spikelet hooks in rows up the banksia cone. The reveal is driven by the real path lengths, computed at load for every path. One constant drawing speed is fixed first, and each specimen's path set is scaled so its total length draws in an authored duration inside three to four seconds, asserted in the code. On screen the drawn length of each path is shown through its stroke dash offset, so the line grows at the same steady pace from the first stem segment to the last detail tick. One line weight is used throughout, 2.5 design units, never varied, with no exceptions.

After each drawing completes it holds, fully drawn, for exactly four seconds, then the next specimen begins from a blank sheet. A tap skips immediately to the start of the next specimen's drawing, and the cycle carries on from there. Frame one opens with the gum blossom already part-drawn, mid-reveal, its stem and cup drawn and its stamens still growing, so the drawing hand is visible at once. Nothing reloads, and the palette is only black ink, number 1A1A1A, on paper, number FAF8F2.
