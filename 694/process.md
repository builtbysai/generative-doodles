# No.694 "Glacier Quipu" — EXPANSION #84 ceciliavicuna, block 6

## Concept

Vicuña's *El glaciar ido / The Vanished Glacier* (2026, Castello di Rivoli): a quipu acostado over 100 meters long, bamboo and raw wool laid across a disappearing glacier. The piece translates it to the gallery frame: a field of long horizontal cords in ice white, glacial blue, deep glacial and raw wool, stretched left to right over a deep cold dark, crossed by four diagonal bamboo spars. The cords sag between their spar contact points; the field is dense at the top and thins toward the bottom dark, like the thinning ice. The melting is the statement, so there is no text, no slogan, no overlay anywhere: meltwater droplets gather on the lowest cords, fall, and vanish, and across each slow loop a few cords retreat (shorten) while one previously retreated cord is restored. The glacier advances and retreats inside the loop; it never simply disappears in one direction. Watch-only, except that a horizontal drag sends a slow wave through the field, wind over ice.

## Construction

- **Layout (seeded, mulberry32, seed 694001).** Four bamboo spars run diagonally, each defined by top and bottom edge crossings with a seeded lean of 0.05–0.12 of frame width, drawn as runs of segments with small gaps at the nodes so the bamboo reads by its joints. 24 cords sit at heights y = 0.055 + 0.80·f^1.35 (f across the cord index), which compresses spacing toward the top: dense above, thinning below. Each cord takes a palette color, a line width, a sag factor, and a slow sway phase from the same stream.
- **Catenary model.** Each cord's anchors are the frame edges plus its four spar crossings (with small seeded jitter). Between consecutive anchors the cord is drawn as a parabola sampled point by point: y = yBase + 4·sag·u·(1−u), the small-sag limit of the true catenary, with sag proportional to the segment span (sagK 0.045–0.08 per cord) and modulated ±6% by a 53 s breathing cycle, so the whole field breathes almost imperceptibly. Each cord also sways vertically by ~1 px on a 37 s phase. Knot dots mark the spar contact points. Every quantity is a closed-form function of the anchored elapsed time; nothing is integrated, so any frame is exactly reproducible.
- **Advance/retreat schedule.** Four cords are cast once from the seed into roles. A starts shortened, is restored between loop phases 0.30–0.45, and re-shortens between 0.80–0.95 so it matches its frame-one state as the loop wraps. B shortens over 0.15–0.35 and returns over 0.70–0.88. C shortens over 0.45–0.62 and returns over 0.85–0.98. D stands shortened for the whole loop. A retreating cord's drawn span shrinks toward its termination spar (anchor index 2 or 3, seeded); its free end gets a short drooping tail ending in a knot dot, the tail growing with the retreat amount. Retreat amount is a smoothstep function of loop phase only (loop = 180 s), so the state at phase 0 and phase 1 is identical and the loop is seamless.
- **Droplets.** The five lowest cords that never retreat carry meltwater droplets, each on its own seeded cycle (24–44 s). The droplet hangs at the belly of the cord's widest segment: local phase 0–0.5 it forms (radius grows from a quarter to full, stretching downward as it nears release), after 0.5 it detaches and falls with gravity (½·0.22·H·ft²) while fading out over ~2.6 s. Droplet cord 0's offset is set so that at t = 0 its local phase is exactly 0.25: frame one always opens with one droplet mid-formation on a low cord, as specced.
- **Drag wave.** A horizontal drag (pointer movement past a 26 px threshold) records a wave {start time, origin x, direction} on the anchored clock, capped at six live waves. Each wave is a slow front (0.16·W per second) whose passage deepens the sag locally (Gaussian in x, ±5.2 px, decaying over ~3.2 s, envelope closing by 7 s). Pure function of the recorded events; no simulation state.
- **House rules.** Canvas sized from the Visual Viewport API with resize listeners on both visualViewport and window; canvas style width/height pinned in px inside every draw; phone detection via window.screen minimum dimension < 700 with the tall-aspect check as fallback only (on phones the same 24 cords run left to right across the narrow frame, bands compressing vertically). Palette strict: the seven specced colors only, alpha used only on those colors. No audio, no microphone, no text besides the title. rAF typeof-guarded; frame one is the synchronous draw at loop t = 0, never derived from Date.now. A `?seed=tNN` hook pins elapsed time for headless phase inspection and is inert in normal viewing.

## Deviations

- None from the prompt. Two implementation notes: (1) the sag curve is a parabola, the small-sag limit of a catenary, rather than a cosh evaluation per sample; at these sag-to-span ratios the two are visually indistinguishable and the parabola keeps every point a closed-form function of time. (2) The retreat/restoration schedule is arranged so the field state at loop phase 1 equals phase 0 exactly (the restored cord re-shortens late in the loop), which the seamless-loop requirement forces; within any single viewing the motion still reads as cords retreating and one returning, never as a one-way disappearance.
