# No.1002 "Grows With the Audience"

Study #123 yuya-hanai, PP163 "Opt-In Only" (the Elan Mitsua mechanism: a model that only learns what you give it).

## Concept

A dark room split in two. On the left, THE CONTRIBUTION WALL: a grid of small seeded scribble marks, one drawn per second, accumulating for as long as the piece runs. Every mark carries an opt-in state. Untrained marks are gray; opted-in marks glow mint with a soft halo. On the right, THE MODEL: five layer bars beside a generation panel. The model trains only on the opted-in marks, and its attempts redraw those very marks, corrupted by noise that falls as the contributed set grows. Along the bottom, the only text in the piece, and it is the truth: "TRAINED ON N MARKS (ALL OPTED IN)".

The rule is absolute: gray marks never train. There is no auto-opt-in anywhere in the code, not even when the model is starving. With zero opt-ins the generation panel shows pure magenta noise blobs: the piece refuses to fake learning. Tap a gray mark to contribute it; drag across the wall for a mass opt-in; double-tap the model to audit, which freezes the model for six seconds while the wall highlights exactly the marks it trained on and dims everything else to 0.25.

## Construction

Single self-contained index.html, canvas 2D, no external assets. Canvas size comes from the Visual Viewport API with resize listeners on visualViewport and window; draw() pins canvas.style.width/height in px every frame. Phone detection uses window.screen physical size (min dimension < 700px) with the aspect fallback h > w*1.15; on phones the divider shifts to 0.48 so the split stays side-by-side and the counter stays legible.

State model, all closed-form over (piece time, recorded opt-in events):

- Marks: mark i spawns at t = i - 5, so the wall holds 36 marks at frame one (t = 30) and one more every second after. Each mark's scribble is a polyline generated by mulberry32 seeded from its index (five study types: spiral, wave, zigzag hatch, wobbling loop, wandering walk), so any mark can be redrawn identically at any time. Marks draw in over 0.8 s; when the grid outgrows the wall it scrolls so the newest rows stay visible.
- Consent: opt-ins are events {mark, time}. The opted-in set as of any time X is the founding events plus the visitor events with time <= X. Nothing else can enter the set; there is no code path that opts a mark in without a tap or drag on that mark.
- Skill: skill = min(0.92, optedCount * 0.05), a function of the opt-in count only. It never rises with time, passes, or anything else.
- Passes: a training pass runs every 4 s. The attempt for pass p uses the opt-in set as of the pass start, so a contribution visibly changes the next attempt, never the current one mid-draw. The attempt composites up to 5 opted-in marks, chosen by a mulberry32 stream seeded from the pass index: each chosen mark's actual polyline is redrawn at a seeded position and scale inside the panel, with per-point jitter of amplitude (1 - skill) * 0.14 of its size and segment dropout probability (1 - skill) * 0.30, plus round((1 - skill) * 5) residual noise strokes. At skill 0.30 (the founding six) the strokes are recognizably the wall's spirals, waves and hatches, broken and wandering; as the set grows the same strokes come back cleaner. Attempt color blends early #FF4FD8 to late #7DF9C6 by skill. Layer bars light in sequence across each pass (bar index = floor(passPhase * 5)).
- Audit: double-tap on the model side sets auditStart; for 6 s the model side is drawn at auditStart (frozen pass, frozen attempt, bars stopped, panel border whitened) while the wall draws opted-in marks at full strength and all others at alpha 0.25.
- Audio: AudioContext is created lazily inside the first pointer gesture and typeof-guarded throughout. A soft sine chime per new opt-in (pitch steps up with the set size), and a three-tone cluster at each pass boundary whose base frequency rises with skill, so clarity follows dataset size. The visual is complete in silence; the QA renderer never creates the context.
- Determinism: frame one is the synchronous draw at the fixed offset T0 = 30 s; the rAF loop (typeof-guarded) advances piece time as T0 + elapsed since the first frame stamp. No Date.now, no Math.random; every random value comes from mulberry32 streams seeded by mark index, pass index, or the piece seed.

The founding audience (a recorded deviation, made openly): the piece ships with six marks already opted in. They are not a cheat and they are not hidden: they are founding events in the same event timeline the visitor's own taps join, seeded contributions from earlier visitors at t = 4 to 26.7 s, each clamped to land after its mark exists. The brief requires frame one at t = 30 to show a model already training on six marks with the counter reading 6; a truly empty history would show a starved noise panel and a counter of 0, contradicting the specified frame one. The consent rule is untouched by them: they are prior visitors' explicit contributions, part of the piece's presented history, and no mechanism ever adds more on its own.
