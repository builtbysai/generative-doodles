# No.691 — Palabrarmas

EXPANSION #84 ceciliavicuna, prompt block 3 "Palabrarmas" (verified verbatim from TASKS.md).

## Concept

Cecilia Vicuña's Palabrarmas (palabras + armas, words as weapons, begun 1974): a word drawn as the thing it names, the letters themselves pulled apart and rebuilt into the object. One Spanish word at a time stands large on a flat paper ground, like a protest banner with generous empty paper around it. Over a twelve-second cycle the word holds, dissolves into a drifting particle cloud, re-gathers as its object, holds again, then returns to letters before the next word begins. The transformation never settles. The fixed cycle runs VERDAD, AGUA, MANO, TIERRA, RIO, FUEGO, LUNA. The word is the only text in the piece, and it is never a caption: it is the mark itself. No English, no decorative typography, and the object shapes stay glyphic, hand-drawn in spirit, never clip-art literal.

## Construction

- **Renderer adaptation (the stroke font).** The prompt's original approach samples fillText glyphs through an offscreen canvas. The QA renderer has no document.createElement and no offscreen canvas, so the letters are an authored stroke font instead: each needed capital (A, D, E, F, G, I, L, M, N, O, R, T, U, V) is defined as polylines on a 5 x 7 grid, and a word is its letter strokes laid out in a row with 1.7 units of tracking. This is arguably closer to the Palabrarmas themselves, which are hand-drawn pencil works, than a sampled system font would be.
- **Clouds.** Every word cloud and every object cloud is sampled to exactly 720 points, evenly by arc length across all of its strokes, then sorted by polar angle around its centroid. Both clouds being angle-sorted makes particle i's journey mostly radial, so the morph gathers and disperses like breath instead of crossing into spaghetti. All fourteen clouds are precomputed once at load from authored data; nothing is integrated, so any frame is a pure function of the anchored clock.
- **Object glyphs.** Authored point clouds in a [-1, 1] box: VERDAD becomes an eye (ellipse outline, iris, pupil, five lash ticks on the upper arc); AGUA a pair of wave lines with a smoothed teardrop above them; MANO a hand silhouette (a 24-anchor closed path through Catmull-Rom smoothing, four fingers and a thumb); TIERRA a horizon line with a mound arc and seven root strokes descending from its base; RIO a meandering sine spline with two bank lines offset from it; FUEGO a flame outline with a smaller inner flame; LUNA a crescent built from an outer arc and an offset inner arc. Curved anchors pass through a Catmull-Rom smoother so the glyphs keep a hand-drawn wobble rather than a CAD edge.
- **Morph design.** Within each word's 12 s cycle: the word holds for u in [0, 0.27); the morph to the object runs [0.27, 0.50) under a smoothstep, with a dissolve turbulence envelope (a sine hump peaking mid-morph) pushing each particle along its own seeded direction by up to a tenth of the letter height, so the letters visibly come apart while they travel; the object holds [0.50, 0.73); the return morph runs [0.73, 0.96) with the same turbulence in reverse; the word holds again to the cycle boundary. Color follows the same shape value: ink #1A1A1A while the word holds, crossfading to the word's accent as the object forms (VERDAD and FUEGO blood red #A83232, AGUA and RIO river blue #3E7C8C, TIERRA earth brown #5C3A21, MANO and LUNA ink throughout). A sub-pixel sinusoidal shiver, a pure phase function per particle, keeps the holds from reading as machine print. Points are drawn as small filled dots whose radius scales with the letter height (clamped 1.0 to 3.4 px) with a seeded per-dot size factor.
- **Layout.** One scale serves every word: the letter height is uniform across the cycle, set by min(0.9 x viewport width / word width in grid units, 0.38 x viewport height / 7), so long words like VERDAD span the frame and short ones like RIO stand taller in the same band. The object box is sized from the same letter height (half-width min(word pixel width x 0.46, letter height x 2.1); half-height letter height x 1.05), centered on the same center as the word.
- **Interaction.** Watch-only loop. A tap skips to the next word: the tap is recorded on the anchored clock with the delta that lands the effective cycle time exactly on the next word boundary, and draw() adds the deltas of all recorded taps, so frame state stays a pure function of elapsed time plus recorded events. No click-to-reload anywhere. No audio, no microphone.
- **House rules.** Single self-contained file, canvas 2D only, no external assets, no absolute URLs, no date strings, no em dashes, no visible text except the cycling word itself rendered as stroke-font points (the words are the piece, per the prompt). Sizing comes from the Visual Viewport API with resize listeners on both visualViewport and window; canvas style width/height are pinned in px inside draw() every frame. Phone detection via window.screen (min dimension < 700px) with the h > w x 1.15 aspect fallback; the word scales to the phone width and the page ground takes the piece's paper tone. rAF is typeof-guarded and the loop is anchored as elapsed-since-load; frame one is the synchronous draw at phase 0, VERDAD fully formed in ink at the start of its hold. Frame one is never derived from a wall clock.

## Deviations

- The prompt's technical approach samples filled glyphs via fillText on an offscreen canvas; that path is impossible in the QA renderer (no document.createElement, no offscreen canvas) and would also tie the letterforms to a system font. The piece uses an authored stroke font sampled to points instead, per the brief's mandatory adaptation. The visual result (a word made of points that morphs into an object made of the same points) is the prompt's design; only the point source changed.
- Accents for AGUA, FUEGO, MANO and LUNA: the prompt names example accents for VERDAD, RIO and TIERRA. AGUA takes the same river blue as RIO, FUEGO the same blood red as VERDAD, and MANO and LUNA take no accent (ink in both states), staying strictly inside the specced palette.
- The prompt's object list names shapes for VERDAD, MANO and RIO explicitly; AGUA (wave and droplet), TIERRA (rooted mound on a horizon), FUEGO (flame) and LUNA (crescent) are drawn as the direct glyph of what each word names, in the same hand-drawn register.
